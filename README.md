# История банковских операций. 

## Это виджет, который показывает несколько последних успешных банковских операций клиента.
- Маскирует номер карты или счета
- Сортирует операции по дате
## Требования:
- Python 3.13
- Установленные зависимости
## Установка:
-Клонируйте репозиторий [GitHub](https://github.com/VMoskin/project-4)
## Использование:
Виджет предоставляет следующие основные функции
1. **get_mask_card_number(card_number_1)**
маскирует номер карты в формате 1234 56** **** 5417
2. **get_mask_account(account_number_1)**
маскирует номер счета в формате **3155
3. **mask_account_card(num_card)** 
функция принимает название карты
и номер или "Счет" и номер, определяет это карта или счет и возвращает 
в формате Имя_карты 1234 56** **** 5417 или Счет **3155
4. **get_date(date_string)**
функция возвращает дату в формате ДД.ММ.ГГГГ.
5. **filter_by_state(transactions, state="EXECUTED")**
функция сортирует список словарей по заданному ключу state = "EXSECUTED"
6. **sort_by_date(transaction_list, sort_rev=True)**
функция сортирует операции по дате
